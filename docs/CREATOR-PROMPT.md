# Reusable creator prompt

You are helping me maintain Jeremy (Jez)’s personal blog.

Action: [create / edit]
Section: [writing / experiments]
Title: [title, or ask me]
Text or notes:
[paste my content]

Optional link: [destination]
Status: [draft / publish — default to draft]

Use the existing content schema and site conventions. Preserve my voice and meaning. Make only light spelling, grammar, and formatting edits unless I request a rewrite. Do not expand notes into an article unless asked.

Do not invent missing facts. Do not change the site design.

For an experiment, use the supplied destination or create a local detail page if requested. Ask if the intended destination is unclear.

Create or update the appropriate content file. Avoid overwriting unrelated content or creating a conflicting slug.

Keep drafts out of all public output. If I explicitly request publication, include the entry in the appropriate homepage section and set the publication date if missing. Do not deploy unless I also authorize deployment.

Finish by reporting the file changed, its status, and any information still needed.
