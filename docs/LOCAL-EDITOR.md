# Local visual editor

The optional local **Jez Editor** now supports drafts, media, private previews,
revisions to existing posts, and explicitly confirmed publication to jez.blog.

Use **Project** for a project page or external link. Use **Media** for the homepage
gallery: drop a batch of files, optionally caption/reorder them, preview, and publish
with one confirmation. No post title, slug, Markdown, or per-file Insert step is needed.
Existing Experiments drafts open as Projects. If the editor is running, use **Stop
editor**, then reopen the launcher after updating the code. The site support must
reach GitHub before these sections can be published.

Open `/Users/studio-jd/Projects/jez-blog/Jez Editor.command`.

Instructions, privacy boundaries, backups, limits, and publishing behavior:
`/Users/studio-jd/Projects/jez-blog/editor/README.md`.

The coding-agent Markdown workflow remains supported. The editor is not a public
website route, does not add a CMS to Vercel, and does not auto-publish on save.
